## 🚀 Running Locally

The project runs with **zero external dependencies**.

The server is currently running at **[http://localhost:3456](http://localhost:3456)**.

### Using Node.js
```bash
npm start
```

### Using Python
```bash
python3 server.py
```

### Custom Port
```bash
PORT=8080 npm start
```
